# 知识库示例资料

`校园事务测试资料.txt` 是本项目使用的知识库源文件，共三节：

1. 请假申请
2. 奖学金申请
3. 学生证补办

上传到 Dify 知识库后即可复现 README 中的问答与出题效果。

## 注意

- 本文档是**模拟测试资料**，仅用于 Dify 工作流学习与演示，不代表任何真实学校的官方规定。
- 原文中有明确说明："具体审批流程和请假时长限制，以学校实际规定为准"。

## 怎么用它

1. Dify「知识库 → 创建知识库」，上传本文件；
2. 索引方式选「高质量」，嵌入模型选 BGE-M3；
3. 索引完成后，在应用的知识检索节点中选中该知识库；
4. 测试提问「请假需要准备哪些材料」验证检索是否命中。

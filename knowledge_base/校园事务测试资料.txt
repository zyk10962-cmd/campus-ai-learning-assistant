# 校园事务知识库（模拟测试资料）

注意：本文档仅用于 Dify 工作流学习测试，不代表任何真实学校的官方规定。

## 一、请假申请

学生因个人原因需要请假时，应提前向辅导员说明请假原因、请假时间和相关情况。

请假申请应包含：
1. 学生姓名
2. 所在班级
3. 请假原因
4. 请假开始和结束时间
5. 联系方式

具体审批流程和请假时长限制，以学校实际规定为准。

## 二、奖学金申请

学生申请奖学金时，可以提前准备以下材料：
1. 学习成绩证明
2. 综合素质评价材料
3. 获奖证书或相关证明
4. 个人申请说明

具体申请条件、评审标准和申请时间，以学校当年正式通知为准。

## 三、学生证补办

学生发现学生证遗失后，可以先向辅导员或学校相关管理部门咨询补办流程。

咨询时建议准备：
1. 学生姓名
2. 学号
3. 所在学院和班级
4. 学生证遗失情况

具体办理地点、费用和所需材料，以学校实际规定为准。

# 项目结构说明

本文说明仓库中每个目录和文件的用途，方便快速上手和面试讲解。

```
校园事务AI智能学习助手/
├── README.md
├── .gitignore
├── docs/
│   ├── 01-项目结构说明.md
│   ├── 02-工作流设计.md
│   ├── 03-部署与运行.md
│   └── 04-测试记录.md
├── screenshots/
│   ├── 01_workflow_overview.png
│   ├── 02_qa_leave_quiz.png
│   ├── 03_qa_scholarship_quiz.png
│   ├── 04_grading_result.png
│   └── 05_knowledge_base.png
└── knowledge_base/
    ├── README.md
    └── 校园事务测试资料.txt
```

## 各目录用途

| 路径 | 用途 |
|---|---|
| `README.md` | 项目主页说明：功能、工作流、技术栈、运行方式、测试情况 |
| `.gitignore` | 规定哪些文件不进仓库，重点排除 `.env`、密钥、Docker 数据卷和模型文件 |
| `docs/` | 详细文档：结构说明、工作流设计、部署步骤、测试记录 |
| `screenshots/` | 项目运行截图，README 中直接引用，便于查看效果 |
| `knowledge_base/` | 知识库示例文档，可上传到 Dify 复现本项目 |

## 仓库中刻意不包含的内容

| 内容 | 原因 |
|---|---|
| Dify 的 Docker 部署目录与数据卷 | 体积大、含本地运行数据，不适合进仓库 |
| `.env`、API Key、数据库密码 | 敏感信息，公开仓库禁止出现 |
| 模型权重（`*.gguf`、`*.safetensors` 等） | 单文件数 GB，无法也不应上传 |
| 用户对话记录、个人身份信息 | 涉及隐私 |

# 测试记录

本文记录项目在本地 Dify 环境中的实际验证情况。截图见 `screenshots/` 目录。

## 测试环境

| 项目 | 配置 |
|---|---|
| 平台 | Dify（Docker 自托管） |
| 对话模型 | Qwen3:8b（Ollama 本地运行） |
| 向量模型 | BGE-M3（Ollama 本地运行） |
| 知识库 | 校园事务测试资料.txt（请假、奖学金、学生证补办三节） |

## 已完成的测试

### 1. 请假申请场景

- 问题：`请假需要准备哪些材料`
- 结果：正确检索到「请假申请」段落，列出学生姓名、所在班级、请假原因、请假时间、联系方式五项；同时生成知识点总结和一道选择题，回答下方展示引用来源。
- 截图：`02_qa_leave_quiz.png`

### 2. 奖学金申请场景

- 问题：`奖学金申请通常需要准备哪些材料`
- 结果：正确提取学习成绩证明、综合素质评价材料、获奖证书、个人申请说明四项材料，并提示具体条件以学校当年正式通知为准；生成「下列哪项不属于奖学金申请的必备材料」选择题，引用区域显示命中知识库文档。
- 截图：`03_qa_scholarship_quiz.png`

### 3. 答案批改与评分

- 操作：对请假场景的选择题提交答案 `a`
- 结果：返回「批改结果：正确题数 1，总题数 1，得分 100」；给出正确答案 A（学生照片）及解析；并附知识点总结，强调区分必备材料与非必备材料。
- 截图：`04_grading_result.png`

### 4. 知识库外问题（边界控制）

- 问题：`食堂几点开门`（知识库未收录）
- 结果：未检索到相关内容，系统提示用户咨询学校相关部门，未编造具体时间。

### 5. 引用展示

- 结果：每次基于知识库回答时，回答下方「引用」区域均正常显示命中的文档（校园事务测试资料.txt）。

## 说明

- 以上场景均为手工在 Dify 预览/聊天页面中实际运行验证，截图取自真实对话。
- 知识库为模拟资料，分类结果以学校实际规定为准；本文只记录"系统是否能正确检索并作答"，不涉及真实校规的准确性。
- 未测试的部分：多题连续练习、多选题与填空题批改、并发压力，均列入后续计划。
